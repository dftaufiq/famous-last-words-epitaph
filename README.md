A one-line tombstone epitaph of famous last words (100 characters): a dead driver confesses he spent 14 months ignoring the check-engine light, then delivers the reversal — the car is fine, he is not. Written for make.fun's "Famous Last Words: The Funniest Epitaph" bounty; `main.py` writes the line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

(Set `OUTPUT_DIR` to write `entry.txt` somewhere other than `/output`.)
